# Instruccions

  

Per poder realitzar la pràctica, cal utilitzar la màquina virtual proporcionada i consultar el manual d'usuari proporcionat.

  

També teniu a la vostra disposició un vídeo d'ús general de la màquina virtual. Encara que estigueu familiaritzats amb l'ús de màquines virtuals, us recomanem que el veieu, ja que podeu trobar algun suggeriment o idea nova que us faciliti el desenvolupament de les activitats.

  

## Descàrrega de fitxers

  

Des d’un terminal de la màquina virtual, clona el repositori GitHub de la PRA1 al directori **Documents** de l’usuari `student`:

  

    git  clone  https://github.com/planetacomputer/Opt26-PRA1  /home/student/Documents/Opt26-PRA1
Un  cop  clonat  el  projecte,  canviem  de  directori  per  entrar  al  del  repositori  descarregat:

    cd  /home/student/Documents/Opt26-PRA1
A partir d'aquí, ja podeu seguir les instruccions de la PRA1.
